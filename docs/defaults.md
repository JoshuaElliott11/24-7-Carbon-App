# Defaults

## Purpose
Defaults enable zero-upload demo runs. They are illustrative and versioned.

## Files
- `defaults/technology_efs.json`
- `defaults/grid_intensity_country.json`
- `defaults/demo_profiles.json`

## Technology EF Defaults
Contains operational and lifecycle factors by technology.
Source labels: NREL review and OWID lifecycle compilations.

## Grid EF Defaults
Contains country-level annual-average factors plus UK and US regional snapshots.
Source labels: UK GOV conversion factors, EPA eGRID, Ember.

## Demo Profiles
Synthetic hourly profiles for one week:
- office-like load
- solar profile
- wind profile
- default site and resource coordinates for deliverability test

## Compliance Note
Defaults are not a compliance-grade substitute for contractual factors, residual mix factors, or jurisdictional guidance.
